How the agent works

ConnectsRead-only access to your database (SQLite here; same pattern for Postgres/BigQuery). No data leaves your machine except queries.
Profiles firstIt never assumes: row counts, nulls, duplicates, format chaos, and column meanings get checked before a single conclusion is drawn.
Analyses on commandSQL for facts, Python for modeling, its forecast tool always compares against a naive baseline and reports honest 80% bands.
Delivers filesThe report is the product: PDF, Excel, and Word deliverables generated in-session, numbers-first and limitations included.

Honesty notes: the demo database is public NYC Open Data (motor vehicle collisions, retrieved Sept 2026) with a synthetic legacy-export layer (duplicates, mixed formats) standing in for a client's messy copy. The agent's reasoning loop is the same one that powers Hermes Agent (Nous Research) — profile first, cite row counts, compare against baselines, disclose limits.
