Accessibility and privacy

Target: WCAG 2.2 AA. Every chart has a text name and a table view, every focusable chart mark has a spoken name, tooltips open on keyboard focus and close with Esc, the scorecard is a real table on every screen size, and text contrast is checked at build (worst pair {{d contrast_worst}}). Behaviour is checked in a headless browser at build time (tools/check_ui.js). Known gaps: the charts need JavaScript (their figures are in the text and in the data files without it), and the page has not been tested with a screen reader by a person.
